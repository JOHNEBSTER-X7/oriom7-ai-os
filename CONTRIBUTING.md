# Contributing

- Preserve the approved hybrid-search and hybrid-model architecture.
- Prefer a modular application and clear domain boundaries before microservices.
- Keep provider integrations behind interfaces.
- Treat citations, provenance, privacy, tenant isolation and cost controls as core features.
- Record material architecture changes as ADRs.

Workflow: open an issue with acceptance criteria, work on a focused branch, add tests, run quality/security checks, then submit a pull request. Never commit secrets or personal data.
